# LoRa 接收灵敏度测试

## **[英文](./README.md) | 中文**

本示例用于通过支持LoRa波形的射频信号发生器，对LoRa接收通路执行传导
接收灵敏度测试。示例只负责接收，不会发射射频信号。

程序根据当前配置和自动检测结果选择对应无线芯片：

| 无线芯片 | 测试频率 |
| --- | ---: |
| SX1262 | 920 MHz |
| LR2021 | 433 MHz |
| LR1121 | 2450 MHz |

这些频率与当前硬件射频通路相匹配，不应在未确认射频匹配网络和法规要求时
随意修改。

## 测试判定

程序使用 Semtech 数据手册的 LoRa 灵敏度条件：

- 带宽：125 kHz
- 扩频因子：由 `kSpreadingFactor` 设置，默认为SF12
- 编码率：4/5
- 前导码：8 symbols
- Header：Explicit
- Payload：64 bytes
- Payload CRC：开启
- IQ：Standard
- Sync Mode：Public，对应 `0x34`
- 低数据率优化：根据SF和带宽自动选择
- 接收增益：Boosted
- 通过条件：PER 不大于 1%

修改 `lora_rx_sensitivity.h` 中的 `kSpreadingFactor` 即可统一改变
LR2021、SX1262和LR1121的实际接收SF，有效范围为5至12。以上是程序默认配置；
LR1121在2.4 GHz使用BW125不属于其数据手册规定范围，不能直接套用官方
灵敏度，具体例外见下文表格。

射频信号发生器必须精确发送1000包。PER计算方式为：

```text
PER = (期望包数 - 正确包数) / 期望包数 × 100%
```

CRC、Header、长度、Payload 内容和读取错误均不会计入正确包。接收端完全
没有观察到的包由期望包数推算为丢包。

等待首包期间，串口每5秒输出一次状态日志。测试进行期间，每5秒输出一次
阶段结果，包括包计数、错误分类、完成度、已观察错误率、RSSI和SNR；正式PER
只在测试结束后计算。

## 射频信号发生器配置

将测试仪器设置为LoRa信号源，并确保以下项目与程序完全一致：

| 测试仪器项目 | 设置 |
| --- | --- |
| Frequency | 与上表对应的芯片频率一致 |
| Spreading Factor | 与 `kSpreadingFactor` 一致，默认SF12 |
| Bandwidth | 125 kHz |
| Coding Rate | 4/5 |
| Preamble Length | 8 |
| Header | Explicit |
| Data Source | All 1 |
| Payload Length | 64 bytes |
| Payload CRC | On |
| Sync Mode | Public，必须对应 `0x34` |
| IQ | Standard |
| Payload Reduced Coding Mode | On |
| Packet/Sequence Count | 1000 |

数据源必须选择 `All 1`。Payload 长度为 64 字节时，程序期望收到的每个
Payload 字节均为 `FF`：

```text
FF FF FF FF FF FF FF FF FF FF FF FF FF FF FF FF
FF FF FF FF FF FF FF FF FF FF FF FF FF FF FF FF
FF FF FF FF FF FF FF FF FF FF FF FF FF FF FF FF
FF FF FF FF FF FF FF FF FF FF FF FF FF FF FF FF
```

不要使用无限重复模式。每一个功率点必须重新发送精确的配置包数。
帧周期必须长于LoRa包的空中时间，并给接收程序预留重新进入RX的时间。
如果相邻包太密，即使输入功率很高也可能产生软件处理造成的丢包。

## 射频连接与功率校准

建议使用传导连接：

```text
RF信号发生器RF OUT -> 固定衰减器 -> 射频线缆 -> 被测设备射频口
```

被测设备端输入功率为：

```text
DUT输入功率 =
    RF信号发生器输出功率 - 固定衰减器损耗 - 线缆及转接头损耗
```

如果测试仪器已经配置外部衰减或用户修正，应使用仪器校正后的端口电平，
不能重复扣除同一段损耗。

## RF Level下限与官方灵敏度参考

测试仪器上设置的是射频输出功率 `RF Level`，单位为dBm，并不是接收芯片
测量得到的RSSI。RSSI只能由接收端对已经检测到的数据包进行估算，不能在
测试仪器上直接设置。

如果使用R&S SMBV100B，其规格书给出的标准射频输出电平特性如下；使用其他
型号的信号发生器时，应以对应仪器的规格书和校准报告为准。

| 仪器项目 | 官方规格 | 测试含义 |
| --- | ---: | --- |
| 1 MHz至6 GHz可设置范围 | -145 dBm至+20 dBm | 仪器界面能够直接输入的范围 |
| 10 MHz至6 GHz规定电平范围 | -127 dBm至+18 dBm | 规格书保证电平特性的范围 |
| 电平设置分辨率 | 0.01 dB | 不代表整个范围内都有0.01 dB绝对精度 |

因此，SMBV100B可以设置到 `-145 dBm`，但低于 `-127 dBm` 的直接输出已经
超出规格书的规定电平范围。需要进行可复现的定量测试时，建议加入固定衰减器，
使仪器本身的输出保持在 `-127 dBm` 以上，再通过衰减得到更低的DUT输入功率。

芯片绝对最佳灵敏度条件与常用对比条件如下。绝对最佳条件使用芯片支持的
较小带宽，可以取得更低的典型灵敏度，但空中时间更长，对频偏和时钟漂移
也更敏感，因此不作为本示例的统一默认配置。官方灵敏度表示在规定测试条件下
满足 `PER = 1%` 的典型DUT输入功率，不是串口RSSI必须精确显示的数值。

| 芯片 | 绝对最佳灵敏度条件 | 官方典型灵敏度 | 常用对比条件 | 常用条件灵敏度 |
| --- | --- | ---: | --- | ---: |
| LR2021 | SF12 / BW31 kHz / RX Boost Mode 7 | -147 dBm | SF12 / BW125 kHz / RX Boost Mode 7 | -141.5 dBm |
| SX1262 | SF12 / BW10.4 kHz / RX Boosted | -148 dBm | SF12 / BW125 kHz / RX Boosted | -137 dBm |
| LR1121 Sub-GHz | SF12 / BW62.5 kHz / RX Boosted | -144 dBm | SF12 / BW125 kHz / RX Boosted | -141 dBm |
| LR1121 2.4 GHz | 最小支持BW203 kHz | 没有对应的SF12官方值 | 不能使用BW125 | 无对应指标 |

表中数值是数据手册规定条件下的芯片射频端典型值，不包含射频开关、滤波器、
匹配网络、PCB、线缆和转接头损耗，也不是产品必须保证达到的最差值。

LR1121这一行不能套用Semtech产品表中的 `-141 dBm`，因为该值对应
SF12/BW125的Sub-GHz条件。LR1121数据手册规定2.4 GHz LoRa带宽范围为
203 kHz至812 kHz，当前2450 MHz/BW125组合不属于官方规定范围；数据手册
给出的2.4 GHz典型参考值之一是 `-129 dBm @ SF7/BW406`。在修改程序和仪器
为官方支持的2.4 GHz带宽以前，不应为当前组合声明官方灵敏度。

下面给出无线路损和使用20 dB固定衰减器时的仪器设置示例。表中的20 dB仅用于
说明计算方法，实际测试必须代入实测的衰减器、线缆和转接头总损耗。

| 芯片 | DUT目标扫描范围 | 总损耗0 dB时的RF Level | 总损耗20 dB时的RF Level | 成功收包时Signal RSSI的预期量级 |
| --- | ---: | ---: | ---: | ---: |
| LR2021 | -130 dBm至-145 dBm | -130 dBm至-145 dBm | -110 dBm至-125 dBm | 约-130 dBm至-145 dBm |
| SX1262 | -125 dBm至-140 dBm | -125 dBm至-140 dBm | -105 dBm至-120 dBm | 约-125 dBm至-140 dBm |
| LR1121 | 当前组合无官方范围 | 不作为官方判定依据 | 不作为官方判定依据 | 不作为官方判定依据 |

仪器应按下面的公式设置：

```text
RF Level = 目标DUT输入功率 + 实测总路径损耗
```

例如总路径损耗为20 dB、LR2021目标DUT输入功率为 `-141.5 dBm` 时，仪器
应设置为 `-121.5 dBm`。如果仪器已经启用外部衰减补偿并直接显示校正后的
DUT端口电平，则不应再次加上20 dB。

`Signal RSSI`通常会接近校准后的DUT输入功率，但会受到芯片估算方法、噪声、
负SNR和射频通路误差影响；`Packet RSSI`还可能与其存在明显差异。灵敏度最终
必须由校准后的DUT输入功率和 `PER <= 1%` 判定。完全不能解调数据包时不会产生
有效RSSI，因此不能把RSSI读数本身当作灵敏度通过条件。

## 操作步骤

1. 在 `menuconfig -> Example Configuration` 中选择
   `lora_rx_sensitivity`。
2. 将测试仪器SF配置为与 `kSpreadingFactor` 一致，并设置为精确发送1000包。
3. 启动本示例，等待串口输出接收端已经就绪。
4. 开启测试仪器的调制与RF输出，发送精确的配置包数；接收端观察到的
   第一个数据包事件会自动开始当前功率点的统计。
5. 观察到1000个数据包事件时程序会自动结束；信号流停止并持续空闲10秒后
   也会自动结束。
6. 记录最终PER，然后降低测试仪器输出功率；下一段数据包流会自动开始
   下一个功率点。
7. 测试期间可随时按下一次BOOT，丢弃当前统计、重新启动接收并等待新一轮
   1000包测试；按键后需要重新启动测试仪器的发送序列。

灵敏度结果是经过线损校准后，仍然满足 `PER <= 1%` 的最低DUT输入功率。
Packet RSSI、Signal RSSI和SNR只作为辅助记录，不作为通过条件。

建议先在比数据手册典型灵敏度高10至15 dB的位置确认PER接近0%，然后按
1 dB步进降低功率；接近1% PER临界点后改为0.5 dB步进。

## 注意事项

- 测试仪器发送包数必须和程序的期望包数完全一致。
- 如果一个功率点完全没有产生任何接收事件，接收端无法独立判断测试仪器
  是否已经发送完成，此时应按100% PER记录该功率点。
- 附近不应有使用相同频率、同步字和LoRa参数的其他发射设备。
- 测试期间不要启用当前示例以外的高负载功能。
- 芯片数据手册给出的是典型值；整机射频口还包含开关、滤波器、匹配网络和
  PCB带来的损耗。
